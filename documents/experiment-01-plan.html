Flow Matching One / Experiment 01

How much condition information
does one-step generation need?

Train a model to move points from a Gaussian cloud onto a spiral. Test whether specifying the destination more precisely helps the model reach the spiral in one step.

01Question and scope

Hypothesis: reducing the number of possible targets for each condition improves generation with one model evaluation. Additional inference steps provide a comparison.

  • Starting distribution: a 2D Gaussian cloud centered at the origin, with unit variance in each coordinate: x0 ∼ N(0, I2).
  • Target dataset: 50,000 points on a spiral that winds around the origin three times while its radius increases from 0.2 to 2.0, before normalization.
  • Data creation: build the fixed target set in memory when the experiment starts and reuse it across all condition counts.
  • Model and comparison: use a multilayer perceptron (MLP), a small feedforward neural network, to predict velocity; keep its architecture fixed and train separate weights for each number of conditions.

Number the target points i=0,…,N−1 in order along the spiral, where N=50,000. Place them at evenly spaced angles, subtract their mean μ, and divide both coordinates by the same scale a so their average squared distance from the origin is 2, matching the Gaussian.

si = (i + ½) / N,   r(s) = 0.2 + 1.8s,   θ(s) = 6πs
y(s) = r(s) [cos θ(s), sin θ(s)],   x1,i = (y(si) − μ) / a
μ = mean(y),   a = √(mean ‖y − μ‖² / 2),   N = 50,000

The points are evenly spaced in angle, not in distance along the curve. Keep these same 50,000 targets in every run and add no random perturbation to their coordinates, so a condition can identify an exact target.

02One control: number of conditions K

Condition density means the number of distinct conditions K. Split the ordered targets into K equal groups; every target in a group receives the same condition, so knowing the condition narrows the destination to that group.

How the model receives the condition

Assign each group an integer index j, starting at 0, and convert it to a normalized floating-point value c between −1 and 1. Feed this one number to the MLP together with the current position and time.

m = N / K   (targets per condition)
j = floor(i / m),   cK(i) = 2(j + ½) / K − 1

Representation: j is an internal integer label; c is an FP32 input tensor of shape [batch size, 1]. Nearby values of c describe nearby groups along the spiral, and the MLP has the same input size and parameter count for every K.

At inference: choose a group j uniformly, compute c from j and K, and sample independent Gaussian noise. The model receives the position, time, and c; the target coordinates are used for evaluation only.

What should an ideal one-step model predict?

With squared-error training, the ideal velocity at the starting time points toward the average target position for the requested group. This gives an exact reference for distinguishing limited condition information from model error.

At t = 0:   v*(x0, 0, c) = E[x1 | c] − x0
Ideal one-step output:   x̂1 = E[x1 | c]

For K=1, the reference is the average of all 50,000 targets; for K=50,000, it is the exact target selected by c. An actual trained model may differ from this reference.

What this comparison tests: how specifying a smaller destination group changes one-step generation. The condition includes the group's position along the spiral; results will not establish the same behavior for arbitrary categorical labels.

03Simple, continuous-time training

The MLP takes a 2D position xt, time t, and condition c, then predicts a 2D velocity. Train one model for each K using randomly sampled times; evaluate that same model with different inference step counts.

For each training pair, sample a target index i and independent Gaussian noise x0, then choose t uniformly between 0 and 1. Interpolate between the noise and target and train the predicted velocity toward their displacement:

i ∼ Uniform{0, …, N−1},   x0 ∼ N(0,I2),   t ∼ Uniform[0,1)
xt = (1−t)x0 + t x1,i
L = E[‖vθ(xt, t, cK(i)) − (x1,i − x0)‖²]

  • Paired runs: reuse initialization, target-index batches, Gaussian draws, and timestep draws across K for each seed; separate training and evaluation RNG streams.
  • Time sampling: continuous-time training follows the general approach studied by SiT; this experiment uses an MLP and a deterministic linear path.

Uniform continuous sampling almost never trains exactly at t=0; report t=0 error explicitly. Add endpoint oversampling only as a later, separately labeled ablation if this becomes a bottleneck.

04Evaluate quality, coverage, and step count

Use deterministic Euler updates from t=0 to 1. Each S-step run uses tk=k/S and Δt=1/S, with one velocity evaluation per step.

1 step · primary248163264

Generate 50,000 samples for each combination of K, training seed, and step count, with equal draws per condition; reuse the evaluation noise across K and step counts. At K=50,000, this gives one fresh-noise sample for every condition.

Here S is the number of inference steps, a training seed selects a reproducible random-number sequence, and ε is a distance threshold. The main comparison uses training conditions with new noise; unseen conditions are evaluated separately.

MeasureDefinition / purpose
Geometric precision ↑Fraction of generated points within ε of the fixed target set; measures whether samples lie near valid targets.
Geometric recall ↑Fraction of the 50,000 target points within ε of any generated point; detects missing spiral regions.
Sliced Wasserstein-1 ↓Project the generated and target sets onto 256 fixed unit directions, compare their sorted coordinates, and average the absolute differences; measures distribution mismatch.
Conditional precision ↑Fraction within ε of a target belonging to the requested condition; detects correct-looking samples in the wrong group.
One-step reference error ↓Root mean squared Euclidean distance between one-step outputs and their group means; at K=50,000 this is error relative to the exact requested target.
Conditional spreadFor 16 evenly spaced conditions (all if fewer), use 128 noise draws each and compare generated variance with the group's true variance; report absolute values when target variance is zero.

Use ε=0.05 in normalized coordinates as primary, with 0.02 and 0.10 as sensitivity checks; nearest-neighbor metrics use KD-trees. These are explicitly defined toy geometric metrics, not the learned-manifold metric of Kynkäänniemi et al.

Interpretation checks

  • Compare one-step samples with the group-mean reference to separate model error from uncertainty about the requested destination.
  • Treat 64-step samples as a comparison, not ground truth; more steps need not improve an imperfect model.
  • At K=50,000, test 49,999 additional conditions halfway between neighboring training conditions; calculate their targets from the spiral formula.

For the unseen-condition check use s=(i+1)/N for i=0,…,N−2 and c=2s−1, with the original μ and a; all locations lie halfway between neighboring training conditions. Use two noise draws per condition, run the same step-count sweep, and report endpoint RMSE separately from the main comparison.
