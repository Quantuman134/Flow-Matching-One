Experiment 02 / Research plan

Brightness flow matching

Start with a clean ImageNet image. Learn to reach its brightness-adjusted version with SiT-S, then compare training timestep coverage and inference cost.

Date: 2026-10-21. Status: experiment planning.
SiT-S/2From scratch · frozen VAE
4 × 3Training settings × inference NFEs
−1 to +1Exposure range in stops

Question

Train SiT-S to transform clean ImageNet images to their requested exposure. Compare four training timestep settings at NFE 1, 4, and 16, measuring image accuracy, brightness error, and spatial error.

Preprocessing

  1. Decode RGB, apply EXIF orientation, resize the shorter side to 256 with antialiased bicubic interpolation, and center-crop 256 × 256.
  2. Convert to FP32 sRGB in [0,1]. Apply a shared random horizontal flip with probability 0.5 during training.
  3. Sample exposure independently for each image presentation and build its target in memory after preprocessing. Keep the source dataset read-only; record relative-path manifests and hashes.

Brightness

Use linear-light exposure, sampled uniformly from −1 to +1 stops. One stop doubles intensity, −1 stop halves it, and zero preserves the source.

Model and objective

Component Setting
Backbone Official SiT-S/2; 2 × 2 latent patches, 256 tokens.

VAE Frozen stabilityai/sd-vae-ft-ema; deterministic posterior means, latent scale 0.18215; pin the revision.

Encode source and target online, interpolate their latents, then train the predicted velocity against their displacement. Average the squared velocity error over batch, channels, and spatial positions.

Symbol Meaning
μE, D VAE posterior-mean encoder and decoder.
α Latent scale, 0.18215; follows the official SiT trainer.
z₀, z₁ Encoded source and reference latents.
t, zt Sampled interpolation timestep and intermediate latent.
u, vθ Reference displacement and predicted velocity.
z₀ = α μE(2x₀ − 1)  ;  z₁ = α μE(2x₁ − 1)
zt = (1 − t)z₀ + tz₁  ;  u = z₁ − z₀
Loss = average[(vθ(zt, t, e) − u)²]

Training timestep sampling

Timestep t records interpolation progress: 0 = clean source, 1 = adjusted target. Training duration is specified under Training budget.

Sample one timestep per image presentation. K is the number of allowed timesteps; every model receives the same image and update budget.

Setting Sampling Allowed timesteps
Continuous Uniform on [0,1). Any value in [0,1).
16 Uniformly choose one of 16 values. 0, 1/16, …, 15/16.
4 Uniformly choose one of 4 values. 0, 1/4, 1/2, 3/4.
1 Always choose 0. 0.

The discrete grids use Euler's left endpoints. Retain the same real-valued timestep embedding in every model.

Comparison setting Rule
Random streams Separate initialization, data/augmentation, exposure, and timestep streams; share their seeds across runs.
Paired time sampling Draw a shared uniform value for every example; continuous training uses it directly, finite grids round it down to their left endpoint. Consume the draw in the K=1 run as well.
K=1 model Learns the source-to-target residual directly; its one-step result is the direct-regression baseline.

Total image error

RMSE is the typical matching-value error: square the differences, average them, and take the square root. Smaller is better; zero is an exact match.

Metric Comparison Scale
RGB RMSE — primary Matching red, green, and blue values. Normalized sRGB [0,1]; overall image and color mismatch.
Luminance RMSE Matching linear-light brightness values. Normalized luminance [0,1]; brightness-map mismatch.
Identity RMSE Output versus source at zero exposure. Same scale as RGB RMSE; preservation when the target equals the source.
Latent RMSE Final predicted latent versus encoded reference. Scaled VAE latent units; transport accuracy before decoding.
Symbol Meaning
pᵢ, qᵢ Matching reference and generated RGB values.
n, Σᵢ Number of RGB values and sum over those values.
R, G, B Linear-light channel values for luminance calculation.
RGB RMSE = √[(1/n) Σᵢ (qᵢ − pᵢ)²]
Luminance = 0.2126R + 0.7152G + 0.0722B

Luminance uses the W3C definition and the brightness section's linear-light conversion.

Brightness and spatial error

Fit one global gain and offset from reference luminance to generated luminance by least squares. Decompose total luminance MSE into three squared-error components, each with ideal value zero:

Component Calculation Meaning
Mean brightness Squared difference of image-average luminance. Whole-image brightness mismatch; also report the signed mean difference, positive for a brighter output.
Global gain Squared gain difference from 1, multiplied by reference luminance variance. Global contrast mismatch.
Remaining spatial error Average squared residual after the best gain/offset fit. Structural changes and local brightness errors.

The three components sum to total luminance MSE. Taking the square root of that total gives luminance RMSE; RGB RMSE captures color differences as well.

Decomposition definitions
SymbolMeaning
yᵢ, gᵢ, mReference luminance, generated luminance, and pixel count.
μ, ν, σ²Reference mean, generated mean, and reference variance.
a, bLeast-squares global gain and offset.
rᵢResidual: generated luminance minus its global gain/offset prediction.
a = Σᵢ (yᵢ − μ)(gᵢ − ν) / Σᵢ (yᵢ − μ)²
b = ν − aμ  ;  rᵢ = gᵢ − (a yᵢ + b)
Total MSE = (ν − μ)² + (a − 1)²σ² + (1/m) Σᵢ rᵢ²

For reference variance ≤ 10−8, report mean-brightness error plus centered error, comparing each map after subtracting its own mean:

Total MSE = (ν − μ)² + (1/m) Σᵢ [(gᵢ − ν) − (yᵢ − μ)]²

Accumulate in FP64; report valid gain-fit counts and nearly uniform cases separately.
