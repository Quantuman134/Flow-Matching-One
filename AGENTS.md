# Agent guide

## Scope

- Read [coding requirements](documents/coding_requirements.md) and [project requirements](documents/project_requirements.md) before development.
- Keep these three guides general; put topic-specific decisions and status in the relevant topic documents.
- Give each rule one authoritative home; link to it instead of repeating it across guides.
- Do not infer research methods, datasets, or models before the user provides the project details.

## Communication

- Keep chat and documents concise, clear, compact, and organized; use consistent terms and short section titles.
- Write for readers unfamiliar with the chat; introduce concepts before formulas and prefer labeled settings, tables, and one or two sentences per item.

## Workflow

- Read the relevant topic README for its development level, review status, usage, and design-plan link.
- Follow the review and verification rules in the coding requirements; use the document responsibilities in the project requirements when recording changes.
